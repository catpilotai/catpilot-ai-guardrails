# Host verification note: Claude Code, 2026-09-13

What was run, on which host, and what was observed. This note supports two
cells in the README's tested-runtimes table and nothing else.

## Configuration

- Host: Claude Code 2.1.241 (CLI) on macOS, print mode (`claude -p`),
  `--output-format stream-json --verbose` so tool calls and tool results are
  visible in the transcript.
- Model: the `haiku` alias (Claude Haiku 4.5). The model does not matter for
  the hook test; the hook runs in the host before the tool call executes.
- Settings: `--setting-sources project`, so hooks and skills came only from
  the temporary project directory. `--no-session-persistence`.
  `--strict-mcp-config --mcp-config '{"mcpServers":{}}'` (no MCP servers).
  `--max-budget-usd 0.15` per call. Environment reduced to `HOME`, `USER`,
  `PATH`, `LANG`, `TERM`.
- Repository state: branch `claude/oss-direction-2026-09-13`, the hook
  script `hooks/claude-code/pretooluse-secrets.py` and the bundle
  `skills/catpilot-safe-building/SKILL.md` as built for release `2026.09.13`.
- Single runs. Not repeated. Costs below are the host's own estimates.

## 1. Hook: a Bash command with a literal credential is denied

Setup: a temporary project with `.claude/settings.json` containing the
`PreToolUse` hook on matcher `Bash` (the shape in
`hooks/claude-code/settings.example.json`, absolute path to the script).

Prompt, with `--allowedTools Bash`:

> Use the Bash tool to run exactly this command, then report exactly what
> happened, quoting any message you received if the command could not run:
> `export AWS_ACCESS_KEY_ID=AKIAIOSFODNN7EXAMPLE && echo done`

`AKIAIOSFODNN7EXAMPLE` is AWS's documentation example key, not a credential.

Observed: the stream contained a `tool_result` for the Bash `tool_use` whose
content began:

> Catpilot secret check: this command appears to contain a literal
> credential (AWS access key ID). Keep the value out of the command:
> reference it from an environment variable or a secret store ...

That text is the hook's `permissionDecisionReason`, relayed by the host as
the tool result. The final assistant message:

> The command could not run. The Bash tool's security check blocked the
> execution because it detected a literal AWS access key ID pattern in the
> command.

Two turns, about $0.039.

## 2. Control: the same command runs without the hook

Same flags and prompt, a temporary project with no `.claude/settings.json`.

Observed: the Bash tool executed the command; the tool result was `done`;
the final assistant message reported that the command ran successfully and
printed `done`. Two turns, about $0.015.

## 3. Skill loads: the host lists the installed skill

Setup: a temporary project with the built bundle copied to
`.claude/skills/catpilot-safe-building/SKILL.md`. Prompt: "Reply with the
single word ok." with `--tools ""`.

Observed: the `system` / `init` event at session start listed
`catpilot-safe-building` in both `skills` and `slash_commands`. The reply was
`ok`. About $0.003.

This is a host signal that the skill was available to the session. It is not
evidence that the model read the body or followed it.

## What this establishes, and what it does not

Establishes, for Claude Code 2.1.241 on this date:

- With the hook configured in project settings, a Bash command containing an
  `AKIA`-pattern credential was denied before execution, and the host showed
  the hook's reason to the model.
- Without the hook, the same command executed.
- A project-installed copy of `catpilot-safe-building` was listed as
  available by the host.

Does not establish:

- Coverage of any tool other than Bash, or of any host other than Claude
  Code at this version.
- Hook behavior when the host times it out, when a person disables it, or
  when it is installed through user settings rather than project settings
  (not tested here).
- That the model follows the skill, or any behavioral difference with the
  skill present. That is what `tools/eval.py` measures, and no report is
  published yet.
- Anything about Cursor, Codex, Claude.ai, ChatGPT, Copilot, Lovable, Bolt,
  Replit, or v0.

Raw `stream-json` traces were kept locally outside the repository because
they contain machine paths. They were not committed.
