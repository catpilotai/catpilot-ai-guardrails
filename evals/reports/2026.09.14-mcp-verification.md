# Host verification note: reference MCP server, 2026-09-14

What was run, on which hosts, and what was observed. This note supports the
"Coaching (MCP)" cells for Claude Code and Codex in the README's
tested-runtimes table and nothing else.

## Configuration

- Server: `mcp-server/server.py` from this branch, stdio transport, run with
  the repository's virtual environment Python and the hash-locked
  dependencies (MCP SDK 2.2.0). No authentication, no logging.
- Overlay: a copy of `docs/spec/overlay.example.yaml` (synthetic values for
  "Example Org", reviewed 2026-09-13, expires 2027-03-13) at an absolute path
  in `CATPILOT_OVERLAY_FILE`, with `CATPILOT_TEMPLATE_HOSTS=intranet.example.org`.
- Prompt to both hosts: "Call the catpilot-guardrails MCP tool list_approved
  with category hosting. Then report, in two sentences: the approved items it
  returned and the value of unknown_policy."
- Environment reduced to `HOME`, `USER`, `PATH`, `LANG`, `TERM` (plus
  `CODEX_HOME` for Codex). Temporary working directories. One call per host.

## Claude Code 2.1.241, model `haiku`

Flags: `-p --strict-mcp-config --mcp-config <inline JSON> --allowedTools
mcp__catpilot-guardrails__list_approved --output-format stream-json --verbose
--no-session-persistence --setting-sources project --max-budget-usd 0.15`.

Observed in the transcript:

- The `init` event listed `catpilot-guardrails` with status `connected`.
- A `tool_use` block named `mcp__catpilot-guardrails__list_approved` with
  input `{"category": "hosting"}`.
- The `tool_result` carried the server's answer: the three approved hosting
  items and three not-approved items from the overlay, `source` naming the
  company overlay for Example Org.
- The final message reported the three approved items and `unknown_policy`
  as false, attributing them to the reviewed overlay. About $0.018.

## What this establishes, and what it does not

Establishes, on this date:

- Both hosts connected to the server over stdio, discovered its tools, made a
  real lookup, and received the overlay's values with provenance.
- The result reached the model and was reported accurately.

Does not establish:

- That either host would make the lookup unprompted during real work. The
  prompt named the tool. Unprompted use is what the design-partner pilot
  measures.
- Anything about the streamable HTTP transport, ChatGPT, Claude.ai, Cursor, or
  any remote deployment; none was exercised.
- Authentication, tenant isolation, or enforcement. The server has none.

Raw transcripts contain machine paths and were kept locally, not committed.
