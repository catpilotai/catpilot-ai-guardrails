# Support

This is an open-source project maintained by the **catpilotai** GitHub organization. Support is best effort.

## Where to go

| You want to | Do this |
|---|---|
| Report a security issue | Follow [SECURITY.md](./SECURITY.md). Do not open a public issue. |
| Report a bug or a wrong deny or pass | Open an issue with the form that fits. Include the evidence checklist the form asks for, and no real secrets, hostnames or company rules. |
| Ask how to use it | Read [docs/QUICK_GUIDE.md](./docs/QUICK_GUIDE.md) and [docs/INSTALL.md](./docs/INSTALL.md), then open an issue. |
| Propose a change | See [CONTRIBUTING.md](./CONTRIBUTING.md). |

## What is supported

The latest stable release gets fixes. Older releases get a fix only for a security issue, at the maintainers' discretion. What counts as stable, beta or experimental is in [docs/STABILITY.md](./docs/STABILITY.md).
