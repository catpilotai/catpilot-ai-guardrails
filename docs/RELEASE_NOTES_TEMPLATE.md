# Release notes template

Ten lines or fewer. Copy this into the GitHub release.

```
## <YYYY.MM.DD> (stable | patch)

Highlights: <one or two lines, what a user gets>
Changed: <behavior that differs from the last release, or "nothing breaking">
Deprecated: <surface, replacement, earliest removal release, or "none">
Removed: <surface removed after two releases' notice, or "none">
Experimental / beta: <what changed in those tiers, or "none">
Security: <fix and advisory link, or "none">
Upgrade: <one line, or "no action">
Verify: gh attestation verify <file> --repo catpilotai/catpilot-ai-guardrails
Full list: CHANGELOG.md
```
